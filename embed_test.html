Numberblocks — embedding test

Checks whether each video can play in an embedded player (what the TV app uses). Paste a full-episode URL from a Season playlist below to test the real episodes — a full URL or the 11-character ID both work.

Important: if you opened this by double-clicking the file (a file:// address), YouTube checks the page's web origin and can report false errors like 101/150/153 even for videos that embed fine. The trustworthy check is the “Open official embed ↗” link on each card: it loads youtube.com/embed/… on YouTube's own origin — if it plays there, embedding works, and the TV app (which also uses a youtube.com origin) will play it too.
